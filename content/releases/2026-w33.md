## WCPOS App

### Added

- Scan barcodes directly from the product filters using your device camera. ([#913](https://github.com/wcpos/monorepo/pull/913))
- Resume large order reports after interruptions and track their progress beyond 10,000 orders. ([#1023](https://github.com/wcpos/monorepo/pull/1023))
- Filter and sort orders by customer, cashier, store, and other key details. ([#944](https://github.com/wcpos/monorepo/pull/944))
- Browse, filter, and sort the full product and customer catalog without previous paging limits. ([#1051](https://github.com/wcpos/monorepo/pull/1051))
- Recover failed changes from the Database screen, with clear reasons and a safe retry option. ([#1011](https://github.com/wcpos/monorepo/pull/1011))
- Queue receipt emails while offline and send them automatically after reconnecting. ([#1021](https://github.com/wcpos/monorepo/pull/1021))
- Warn cashiers when the server clock differs enough to affect synchronization. ([#924](https://github.com/wcpos/monorepo/pull/924))
- Show an alert when saved order totals differ from the server’s calculation. ([#1036](https://github.com/wcpos/monorepo/pull/1036))
- Allow stock quantities to be edited directly from the Products screen. ([#1100](https://github.com/wcpos/monorepo/pull/1100))
- Show real storage usage, variation totals, and items needing attention on the Database screen. ([#1108](https://github.com/wcpos/monorepo/pull/1108))

### Changed

- Reduce startup work by loading catalog references and product browsing data only when needed. ([#1104](https://github.com/wcpos/monorepo/pull/1104))
- Adapt background polling during periods of heavy server load. ([#1025](https://github.com/wcpos/monorepo/pull/1025))
- Keep the app responsive while processing large catalogs and reports. ([#1022](https://github.com/wcpos/monorepo/pull/1022))
- Coordinate open browser tabs so they share one reliable local data writer. ([#1057](https://github.com/wcpos/monorepo/pull/1057))
- Use your actual account permissions to decide whether catalog items can be edited. ([#1094](https://github.com/wcpos/monorepo/pull/1094))
- Simplify the Performance screen with clearer charts, labels, and time-range presets. ([#1103](https://github.com/wcpos/monorepo/pull/1103))

### Fixed

- Product scrolling, sorting, searching, and filtering now work reliably across large catalogs. ([#1030](https://github.com/wcpos/monorepo/pull/1030))
- Product images display correctly in the web app instead of always showing placeholders. ([#933](https://github.com/wcpos/monorepo/pull/933))
- Prevent duplicate open orders when the same product is scanned repeatedly in quick succession. ([#920](https://github.com/wcpos/monorepo/pull/920))
- Prevent errors when adding products to the cart or completing checkout in the desktop app. ([#965](https://github.com/wcpos/monorepo/pull/965))
- Search variations remotely and refresh their totals and details when the variation picker opens. ([#994](https://github.com/wcpos/monorepo/pull/994))
- Wait until the payment screen is ready before enabling Process Payment. ([#1031](https://github.com/wcpos/monorepo/pull/1031))
- Keep offline receipt emailing available from the receipt dialog. ([#1038](https://github.com/wcpos/monorepo/pull/1038))
- Preserve coupon changes when required catalog data arrives later. ([#1020](https://github.com/wcpos/monorepo/pull/1020))
- Show catalog update rejections clearly and restore the previous value automatically. ([#1091](https://github.com/wcpos/monorepo/pull/1091))
- Prevent temporary total differences from incorrectly marking completed orders as stuck. ([#1041](https://github.com/wcpos/monorepo/pull/1041))
- Prevent phantom orders when one browser tab creates an order while another voids it. ([#1061](https://github.com/wcpos/monorepo/pull/1061))
- Keep connection checks running reliably and restore login compatibility with older servers. ([#1113](https://github.com/wcpos/monorepo/pull/1113))

## WCPOS Plugin

### Added

- Print multiple receipt copies from a single automatic printing rule. ([#1424](https://github.com/wcpos/woocommerce-pos/pull/1424))
- Choose whether each automatic printing rule runs when an order is created or after payment. ([#1525](https://github.com/wcpos/woocommerce-pos/pull/1525))
- Add an audit trail to orders created or updated through WCPOS. ([#1433](https://github.com/wcpos/woocommerce-pos/pull/1433))
- Sort customers by their WordPress role. ([#1500](https://github.com/wcpos/woocommerce-pos/pull/1500))
- Preserve the original cashier attribution throughout the lifetime of a sale. ([#1505](https://github.com/wcpos/woocommerce-pos/pull/1505))

### Changed

- Give cashiers product creation and editing permissions by default while keeping deletion opt-in. ([#1541](https://github.com/wcpos/woocommerce-pos/pull/1541))
- Reduce synchronization traffic with smaller update checks. ([#1543](https://github.com/wcpos/woocommerce-pos/pull/1543))
- Reduce the packaged plugin size by 2.4 MiB. ([#1538](https://github.com/wcpos/woocommerce-pos/pull/1538))

### Fixed

- Apply updated variable-product prices immediately instead of returning stale saved values. ([#1436](https://github.com/wcpos/woocommerce-pos/pull/1436))
- Exclude hidden variations from the WCPOS product catalog. ([#1443](https://github.com/wcpos/woocommerce-pos/pull/1443))
- Improve order-total precision and preserve custom POS pricing during calculations. ([#1468](https://github.com/wcpos/woocommerce-pos/pull/1468))
- Remove order items that were deleted in WCPOS when the full order is saved. ([#1477](https://github.com/wcpos/woocommerce-pos/pull/1477))
- Prevent duplicate variation attributes after an order is synchronized again. ([#1499](https://github.com/wcpos/woocommerce-pos/pull/1499))
- Keep restored orders visible and synchronized when using High-Performance Order Storage. ([#1508](https://github.com/wcpos/woocommerce-pos/pull/1508))
- Calculate taxes correctly for multi-store orders. ([#1545](https://github.com/wcpos/woocommerce-pos/pull/1545))
- Fix stale license keys when downloading WCPOS Pro updates. ([#1444](https://github.com/wcpos/woocommerce-pos/pull/1444))
- Improve the security of custom thermal receipt templates. ([#1428](https://github.com/wcpos/woocommerce-pos/pull/1428))
